# Release v0.1.2

## 📝 Docs

- 新增 `## 核心理念` 段落，置于安装说明之前：依靠可控的输入需求确认与必须的输出字段确认，维持 LLM 在多次相同/不同任务中工作稳定且不偏离。分三处展开——输入侧动手前只读探查并按固定字段复述意图、不确定项当场做成带选项的提问；输出侧每轮收尾按固定字段交付、字段缺失即视为未完成；两端格式约束共同构成稳定性来源。
- 首段简介不再以「把 pi-dev-workflow 移植到 DSH」开头，改为直接描述本插件自身提供的命令与工具。
- 删除 `## 与 pi 版本的差异` 整节，以及首段「提示词文本从 pi 逐字移植」一句。
- 删除 `不在范围内` 一行：该行列举的是 pi 中存在而本插件未实现的命令，属于迁移语境，独立项目下不再成立。
- 目录结构补齐 v0.1.1 已落地但未记录的内容：`.version/` 目录、`release.yml`、`test/version.test.mjs`。
