# Release v0.3.0

需求理解改为优先读取 `prompt-check`，新增三个原生 Skill，并更新精简版全局规则。

## 兼容范围

- 本版以开发时 npm `latest` 的 DSH `0.2.1-rc.5` 为基准，engine 与 DSH 依赖精确声明该版本；不采用 `0.2.2-alpha.2`。
- 更旧 DSH 及其他版本不在本版声明范围；README 提供插件与 DSH 对照表。
- `0.1.1` 至 `0.2.1` 的历史依赖基准为 DSH `0.2.1-rc.2`，本轮未重新验证历史组合。

## 变更

- 使用用户提供的新版八节 Global Agent Rules，保留追加系统提示词而非覆盖宿主提示词的语义。
- 新增 `prompt-check`、`project-audit-review`、`issue-to-pr`，通过官方文件系统 provider 注册为 bundled 技能，随 npm 包分发。
- 五个 `dev-*` 命令在每次复述前读取当前作用域与有效项目目录的 `prompt-check`，正文修改在下次读取生效。
- 沿用 DSH 原生项目、运行时、用户及 bundled 技能优先级，不覆盖用户同名技能。
- 技能未找到、正文为空、读取失败或禁止模型调用时明确提示，并使用按新版技能更新的内置保底流程；宿主中止不降级执行。
- 保留命令确认卡、修正、补充与取消交互，避免 Skill 与命令重复确认；移除 `dev-feat` 的重复计划确认要求。
- 有效工作目录改为优先读取 DSH `workingDirectory` 服务，技能发现与默认验收探测使用相同目录。
- 补齐需求输入、超时重试及确认答案与中止同时返回时的边界，防止中止后继续投递执行任务。

## 验证

- 隔离临时目录按新锁文件执行 `npm ci --no-audit --no-fund` 成功，未使用 `--force` 或 `--legacy-peer-deps`。
- 干净安装下六套测试通过：命令、工具 schema、客户端预览、系统提示词追加、真实 Skill/插件入口集成、版本说明。
- 新增验证覆盖全部命令的技能优先和取消、技能重读、明确降级、有效目录、并发中止、作用域优先级、完整正文、卸载及重新挂载。
- `lib/*.js` 与 `test/*.mjs` 语法检查、`git diff --check` 通过；npm 打包预览确认三个 `SKILL.md` 均包含在包内。
- 本地运行环境为 macOS arm64、Node `26.13.0`、npm `11.20.0`；Node 22/24 由 CI 另行验证，不把本地结果当作远端结果。
- 原锁文件直接升级曾触发 `ERESOLVE`，已通过隔离重新解析依赖解决；Python Skill 校验器缺少 PyYAML，改用 YAML 解析及 DSH 原生解析、完整正文比对验证。

## 限制

- 未运行真实 LLM 与全部宿主客户端端到端会话；提示词约束不等同于文件系统沙箱。
- 原生加载保留完整 Skill 正文；长技能经模型工具加载后仍可能受宿主上下文压缩的工具结果裁剪，本插件不修改该策略。
- 标签推送触发 npm 公开发布及 GitHub Release，两项工作流独立，实际结果应分别核实。
